Vibe Coding – 灵感画布 画布类AI应用

充分利用 TimiAI 算力，整合文生文、文生图、图生视频等多模态 AI 技术，大幅降低内容制作门槛并提升创作效率。

技术实现

  • CodeBuddy + Claude-Opus-4.7 (1M context)
  • React + TypeScript + Vite
  • TimiAI WebTask + API Key
  • 图片生成链路从直接 API 调用（LOCAL 模式）重构为后端 WebTask 异步任务模式
  • 集成 Wujie 微前端，接入 TimiAI 主应用（wujie-bridge 透传 token / userInfo / appGroupId）
